# Публикация исходников виджета в GitHub

Пакет виджета хранится в публичном репозитории только как исходный код. В репозиторий нельзя добавлять:

- `.env` и любые токены, пароли, OAuth-ключи;
- приватный адрес n8n webhook для ручного добавления PDF;
- экспортированные PDF, ZIP-сборки и `node_modules`;
- данные сделок, переписок и клиентов.

## Безопасный состав исходников

Публикуются:

- `manifest.json`, `script.js`, `style.css`;
- `templates/`, `i18n/`, `images/`;
- `server/src/`, `server/test/`, `server/package.json`, `server/.env.example`;
- документация и тесты.

## Конфигурация окружения

Расчётный Cloudflare API можно держать в открытом коде, если он не выдаёт ключи и принимает только предусмотренные публичные запросы. Адрес ручного добавления PDF в amoCRM является приватной конфигурацией: его задают только в закрытом окружении при сборке/установке виджета.

В публичном GitHub-исходнике кнопка «Добавить PDF» не должна содержать действующий n8n webhook. До передачи в amoCRM в рабочую сборку вручную подставляется закрытая конфигурация.

## Перед публикацией

1. Проверить `git status --ignored` и убедиться, что секреты не попадают в индекс.
2. Запустить тесты калькулятора и `server/test/draft-service.test.mjs`.
3. Проверить, что тестовые Avito-воркфлоу выключены и не отправляют сообщения.
