# Помощник по расчёту для amoCRM

Это исходный код виджета для правой панели карточки сделки (`lcard-1`). Он **не отправляет сообщения клиентам и не меняет поля, статус или название сделки**. Расчёт получает только от выделенного API черновиков.

Репозиторий публичный: в нём намеренно отсутствуют токены, ключи, клиентские данные и приватный n8n webhook для ручного прикрепления PDF.

## Что уже готово

- компактная панель «Помощник по расчёту» в голубой палитре;
- поле свободного запроса для расчёта/черновика ответа;
- режим `draft_only` жёстко задан в запросе;
- понятные состояния: пустой ввод, сервер не подключён, ошибка;
- расчёт через публичный API цен, который не выдаёт секреты;
- ручное прикрепление PDF в публичном исходнике заблокировано; оно включается только в закрытой рабочей сборке.

## Что нужно перед установкой

1. Подключить пакет как приватный виджет amoCRM.
2. Разместить сервер из папки `server/` за HTTPS. Он принимает только `POST /v1/drafts` и возвращает черновик.
3. Для рабочей сборки отдельно задать закрытый endpoint прикрепления PDF. Его нельзя коммитить в этот репозиторий.
4. Упаковать содержимое папки в ZIP и установить как приватный виджет.

## Контракт сервера

Запрос:

```json
{"mode":"draft_only","lead_id":36413089,"request":"60 м профлиста, ворота и калитка"}
```

Ответ:

```json
{"title":"Черновик сметы готов","detail":"Проверьте параметры перед использованием"}
```

В ответе нельзя возвращать персональные данные или текст переписки. PDF и запись в amoCRM будут отдельными, подтверждаемыми этапами после теста.

## Локальная проверка

```bash
cd amo-widget/server
node test/draft-service.test.mjs
```

Сервер по умолчанию выключен (`WIDGET_SERVER_ENABLED=false`), поэтому его нельзя случайно подключить к CRM. До установки приватной интеграции и OAuth-защиты включать его нельзя.
